       - 提供一个小函数（示例命名：`IsSensitiveHeaderKey(key string) bool` 或 `ShouldOmitHeaderFromLogs(key string) bool`）。
       - 至少覆盖（大小写不敏感，支持常见变体）：

         - `Proxy-Authorization`

       - 其余 header 继续写出，但仍可保留 `MaskSensitiveHeaderValue` 作为第二道保险。
       - 额外要求：确保对 `X-Management-Key` 也不会落盘（目前可能未被 mask）。

    3) 保持现有日志格式与结构（方便比对），只改变敏感头的输出行为。
