## 滑动窗口要求（来自 CONTEXT.md）

### 窗口配置
- 大小：100 次请求
- 维度：每个 provider + model 组合分别统计
- 存储方式：内存中环形缓冲区，循环覆盖

### 统计指标
- TPS、TTFT、TPOT 全部计算
- 统计值：最小值、最大值、平均值、中位数、p95、p99

### 百分位计算
使用标准算法计算 p95 和 p99：
- 对样本排序
- p95 = 第 95 百分位的值
- p99 = 第 99 百分位的值

  <files>internal/metrics/window.go</files>
  <action>
创建 internal/metrics/window.go，实现：

1. SlidingWindow 结构体：
   - buffer [100]RequestMetrics（固定大小数组）
   - head int（下一个写入位置）
   - count int（当前有效元素数量，最大100）
   - mu sync.RWMutex

2. 方法：
   - NewSlidingWindow() *SlidingWindow - 构造函数
   - Add(m RequestMetrics) - 添加新指标到窗口
     - 写入 buffer[head]
     - head = (head + 1) % 100
     - 如果 count < 100，count++
   - GetAll() []RequestMetrics - 返回当前窗口中所有有效元素（复制）
   - Len() int - 返回当前元素数量

3. 辅助函数：
   - calculatePercentile(sorted []float64, p float64) float64
     - 使用标准百分位计算：index = (p/100) * (n-1)
     - 如果 index 不是整数，线性插值

注意：所有方法需要加锁保护并发访问。

  <name>Task 2: 实现窗口统计计算</name>
  <files>internal/metrics/window.go</files>
  <action>
在 window.go 中添加 WindowStats 计算功能：

1. SlidingWindow 方法：
   - GetStats() WindowStats - 计算并返回窗口统计

2. 计算逻辑：
   - 提取窗口中所有 TPS、TTFT、TPOT 值到三个切片
   - 对三个切片分别排序
   - 计算：
     - Min：第一个元素
     - Max：最后一个元素
     - Avg：总和 / 数量
     - Median：中间元素（或中间两个的平均）
     - P95：calculatePercentile(sorted, 95)
     - P99：calculatePercentile(sorted, 99)
   - 填充 WindowStats 结构体返回

3. 边界处理：
   - 如果窗口为空，返回零值 WindowStats
   - 如果只有一个元素，min=max=avg=median=p95=p99=该值

注意：GetStats 需要读取锁，不要与 Add 的写锁冲突。
