## 计算规则（来自 CONTEXT.md）

### 指标精度
- TPS: tokens/s，保留 2 位小数
- TTFT: 秒为单位
- TPOT: 秒为单位

### 计算公式
- TPS = outputTokens / (EndTime - FirstTokenTime)
- TTFT = FirstTokenTime - StartTime
- TPOT = (EndTime - FirstTokenTime) / outputTokens

### 边界情况
- 空响应（0 token）：丢弃该请求，返回错误
- 请求超时（部分响应）：丢弃该请求，返回错误
- 非流式请求：TTFT = 总响应时间（EndTime - StartTime）

### Token 来源
- 使用 Provider 返回的 usage.completion_tokens

2. CalculateTPS(outputTokens int, firstTokenTime, endTime time.Time) (float64, error)
   - 计算生成时间 = endTime - firstTokenTime
   - 如果生成时间 <= 0，返回错误
   - 如果 outputTokens <= 0，返回错误

3. CalculateTPOT(outputTokens int, firstTokenTime, endTime time.Time) (float64, error)

   - 如果 outputTokens <= 0，返回错误
   - TPOT = 生成时间(秒) / float64(outputTokens)

4. ValidateMetrics(m *RequestMetrics) error

   - 验证时间顺序是否合理
   - 验证 token 数量是否有效
