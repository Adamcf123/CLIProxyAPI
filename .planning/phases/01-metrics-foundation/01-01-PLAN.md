## 项目背景

CLIProxyAPI 是一个 API 代理服务，支持多种 LLM provider（OpenAI、Gemini、Claude）。
代码位于 internal/ 目录，使用 Go 语言编写。

## Phase 1 目标

建立完整的指标计算能力，支持 TPS、TTFT、TPOT 计算，并按 provider/model 分组统计。

## 关键决策（来自 CONTEXT.md）

### 指标精度
- TPS 保留 2 位小数
- TTFT 和 TPOT 使用秒为单位
- 仅统计输出 tokens
- Token 数量来源：Provider 返回的 usage.completion_tokens

### 分组维度
- 基本分组：provider + model
- 额外分组：区分 streaming / non-streaming

### 聚合策略
- 单次请求指标 + 滑动窗口聚合
- 滑动窗口大小：100 次请求
- 滑动窗口维度：每个 provider + model 组合分别统计
- 滑动窗口持久化：进程重启后需要恢复数据

### 边界情况
- 请求超时/空响应：丢弃该请求，不记录任何指标

注意：CompleteRequest 需要计算 TPS = outputTokens / (EndTime - FirstTokenTime)，
