  <action>
Create a new test in package `metricsruntime`:

Precondition (already implemented in current codebase):
- `internal/metricsruntime/usage_plugin.go` detects `usageMissing` (all token counts are 0 and record is not failed) and leaves token pointer fields nil, which the persistence layer stores as NULL.
  This plan adds a regression test to lock that behavior.

If the new test FAILS (regression or drift):
- Fix `internal/metricsruntime/usage_plugin.go` to restore the intended behavior:
  - `usageMissing` must be true when `inputTokens==0 && outputTokens==0 && totalTokens==0 && !record.Failed`.
  - When `usageMissing` is true, token pointer fields MUST remain nil (`InputTokens`, `OutputTokens`, `TotalTokens`).
  - Token-derived metric pointers (`TPS`, `TPOT`) MUST remain nil when output tokens are unavailable.
  - Keep existing behavior: TTFT may still be computed from timestamps if available.

- Test name: `TestMetricsPlugin_NoUsageRecord_PersistsQueryableRow`
- Setup:
  - Create temp SQLite DB via `metricspersist.InitDB` + `metricspersist.Migrate`.
  - Use the existing package-level seam `enqueueMetricRecord` (declared in `internal/metricsruntime/usage_plugin.go`) by overriding it in the test to synchronously insert into this DB.
    - Do NOT start the global async writer; it is process-global and not safely restartable in tests.
  - Create a Gin test context and attach a RequestState:
    - streaming=true
    - set status code to 200
  - Create `ctx` that includes:
    - `logging.WithRequestID(context.Background(), "req_no_usage")`
    - `context.WithValue(ctx, "gin", ginCtx)`

- Execute:
  - Instantiate `p := NewMetricsPlugin(nil)`.
  - Call `p.HandleUsage(ctx, usage.Record{Provider: "openai", Model: "gpt-5.2", Failed: false, Detail: usage.Detail{}})`.

- Assertions (query DB directly):
  - Row exists for request_id "req_no_usage".
  - `input_tokens`, `output_tokens`, `total_tokens`, `tps`, `tpot` are NULL.
  - `status_code` is 200.
  - `streaming` is 1.
  - `error_info` is NULL.

Test hygiene:
- Restore `enqueueMetricRecord` via defer.
- Do NOT use `t.Parallel()`.
  </action>
