  <action>
Create a test file in package `executor` that verifies wiring via static source checks.

Why static checks here:
- True end-to-end streaming execution tests would require upstream simulation and are disproportionately expensive.
- This test is a guardrail to prevent accidentally deleting the required hooks.

Test approach:
- Read the source files listed below by resolving the module root at runtime (so the test works under `go test` from package directories):
  - Use `runtime.Caller(0)` to get the absolute path to the current test file.
  - Walk parent directories until a `go.mod` file is found; that directory is module root.
  - For each checked file, read using `os.ReadFile(filepath.Join(moduleRoot, relPath))`.
  - If `go.mod` cannot be found within a reasonable number of parents (e.g. 10), `t.Fatal` with a clear message.
- Use regex matching (more stable than exact-string checks) to avoid false failures on formatting/variable-name changes:
  - Streaming hook pattern: `defer\s+reporter\.ensurePublished\(\s*\w+\s*\)`
  - Non-streaming hook pattern: `defer\s+reporter\.finalize\(\s*\w+\s*,\s*&err\s*\)`

Files to check:
- `internal/runtime/executor/claude_executor.go`
- `internal/runtime/executor/codex_executor.go`
- `internal/runtime/executor/qwen_executor.go`
- `internal/runtime/executor/gemini_executor.go`
- `internal/runtime/executor/gemini_cli_executor.go`
- `internal/runtime/executor/gemini_vertex_executor.go`
- `internal/runtime/executor/aistudio_executor.go`

Failure messages must name:
- the file missing the hook
- which hook string was missing

Test hygiene:
- Do NOT use `t.Parallel()` (reads stable files, but keep ordering predictable).
