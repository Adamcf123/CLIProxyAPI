  <name>Task 1: Non-streaming paths use reporter.finalize (no defer-order hazards)</name>
  <files>
internal/runtime/executor/claude_executor.go
internal/runtime/executor/codex_executor.go
internal/runtime/executor/qwen_executor.go

  <action>
For each non-streaming execution method that creates a `usageReporter`:

- Replace the existing `defer reporter.trackFailure(ctx, &err)` with a single defer:
  - `defer reporter.finalize(ctx, &err)`

Rationale:
- `finalize` is a single canonical end-of-request hook:
  - publishes failure if `err != nil`
  - then calls `ensurePublished` so no-usage successes still publish
- This removes a fragile dependency on defer ordering.

Do NOT change user-facing output; do not add new logs.

Behavioral intent:
- `reporter.publish(...)` intentionally skips when tokens are all zero and not failed.
- `reporter.finalize(...)` guarantees an emitted usage record exists for counting/persistence.
  </action>
  <verify>go test ./internal/runtime/executor -run Test -count=1</verify>
  <done>
In these executors, a successful request with missing usage still results in one published usage record.
  </done>
</task>
