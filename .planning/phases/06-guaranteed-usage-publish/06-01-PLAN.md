<task type="auto">
  <name>Task 1: Add deterministic seams + a safe finalize helper</name>
  <files>internal/runtime/executor/usage_helpers.go</files>
  <action>
Add a package-level variable seam:

- Introduce `var publishUsageRecord = usage.PublishRecord`.
- Replace direct calls to `usage.PublishRecord(ctx, usage.Record{...})` in:
  - `(*usageReporter).publishWithOutcome`
  - `(*usageReporter).ensurePublished`
  with `publishUsageRecord(ctx, usage.Record{...})`.

Add a non-streaming-safe helper on usageReporter to eliminate defer-order hazards:

- Add `func (r *usageReporter) finalize(ctx context.Context, errPtr *error)`.
- Implement it as a single canonical path:
  - first call `r.trackFailure(ctx, errPtr)` (so failure publishes if needed)
  - then call `r.ensurePublished(ctx)` (so no-usage success publishes, but will be a no-op if already published)

Note: Do NOT use `finalize` for streaming `ExecuteStream` functions that return a channel and start a goroutine; in those cases, ensurePublished must run at end of the stream goroutine.

Why:
- The global usage manager has no unregister/reset; a seam allows synchronous, isolated unit tests.
- Do not change publish semantics: keep once.Do behavior and record fields unchanged.
  </action>
  <verify>go test ./internal/runtime/executor -run TestUsageReporter -count=1</verify>
  <done>
The production publish path remains identical, but tests can override `publishUsageRecord`.
  </done>

<task type="auto">
  <name>Task 2: Add unit tests for no-usage and failure precedence</name>
  <files>internal/runtime/executor/usage_helpers_test.go</files>
  <action>
Create focused unit tests (no goroutines, no global usage manager registration):

1) `TestUsageReporter_Publish_SkipsAllZeroTokensWhenNotFailed`
   - Override `publishUsageRecord` to capture calls.
   - Call `reporter.publish(ctx, usage.Detail{})`.
   - Assert: no record published.

2) `TestUsageReporter_EnsurePublished_EmitsOnce`
   - Override `publishUsageRecord` to capture the record.
   - Call `reporter.ensurePublished(ctx)` multiple times.
   - Assert: exactly one call, `Failed=false`, and token fields are all zero in `Detail`.

3) `TestUsageReporter_PublishThenFinalize_EmitsOnlyOnce`
   - Override `publishUsageRecord` to count calls.
   - Call `reporter.publish(ctx, usage.Detail{OutputTokens: 1, TotalTokens: 1})` (forces a publish).
   - Call `reporter.finalize(ctx, &err)` with `err == nil`.
   - Assert: still exactly one published record.

4) `TestUsageReporter_Finalize_PublishesFailureWhenErrSet`
   - Override `publishUsageRecord` to capture the record.
   - Set `err = errors.New("boom")`.
   - Call `reporter.finalize(ctx, &err)`.
   - Assert: exactly one published record and it has `Failed=true`.

5) `TestUsageReporter_PublishFailureThenEnsurePublished_EmitsFailureOnlyOnce`
   - Override `publishUsageRecord` to count calls + capture the record.
   - Call `reporter.publishFailure(ctx)`.
   - Call `reporter.ensurePublished(ctx)`.
   - Assert: exactly one published record and it has `Failed=true`.

6) `TestUsageReporter_PublishFailureThenFinalize_EmitsFailureOnlyOnce`
   - Override `publishUsageRecord` to count calls + capture the record.
   - Call `reporter.publishFailure(ctx)`.
   - Ensure `err == nil`, then call `reporter.finalize(ctx, &err)`.
   - Assert: exactly one published record and it has `Failed=true`.

Test hygiene:
- Always restore `publishUsageRecord` via defer.
- Do NOT use `t.Parallel()` (shared package var).
